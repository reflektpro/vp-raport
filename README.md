# Электронный рапорт ГУ ВП

Сайт-бланк: боец заполняет рапорт прямо на «листе», жмёт «Отправить», и в Discord прилетает картинка документа с подписью и печатью, пинг руководства и ссылка на боди-камеру. Всё бесплатно: сайт на GitHub Pages, пересылка через Cloudflare Worker.

## Файлы
- `index.html`, `style.css`, `app.js` — сам сайт
- `config.js` — настройки: роли, шапка, текст печати, адрес отправки
- `emblem.png` — эмблема
- `worker.js` — пересыльщик для Cloudflare (прячет ссылку вебхука)

## Запуск за 10 минут
1. **Вебхук.** Discord → настройки канала → Интеграции → Вебхуки → Новый → «Копировать URL».
2. **Worker.** dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Hello World → Edit code → вставь `worker.js` → Deploy.
   В Settings → Variables добавь (тип Secret):
   - `WEBHOOK_URL` — ссылка вебхука
   - `ROLE_IDS` — `1321249388965793844,1321249411954774128,1321249413024452608`
   - `ALLOWED_ORIGIN` — адрес сайта из шага 3 (например `https://nick.github.io`)
3. **Сайт.** Создай репозиторий на GitHub, залей все файлы, кроме `worker.js`. Settings → Pages → Branch: main → Save.
4. В `config.js` впиши `endpoint: "https://имя-воркера.твой-ник.workers.dev"`.

Для быстрого теста можно вместо воркера вписать вебхук в `directWebhook`, но на публичном сайте так не делай: ссылку увидит любой.

## Что умеет
- поля подсвечены прямо на бланке, обязательные проверяются;
- звание, должность и имя отправителя запоминаются в браузере;
- подпись генерируется по имени (у одного имени она всегда одинаковая), печать накладывается автоматически, её можно отключить;
- «Васильев З.» под подписью собирается из имени сам;
- в «Приложение» вставляется ссылка на боди-камеру и при желании другие материалы;
- номер рапорта и дата подставляются сами;
- кнопка «Скачать PNG» без отправки.
